# ⚡ Groq & Flask AI Chatbot

A high-performance, real-time AI Chatbot powered by **Flask** and **Groq's LPU™ Inference Engine**. Features real-time token streaming, rich Markdown formatting, code syntax highlighting with 1-click copying, model switching, and secure `.env` key management.

---

## 🌟 Key Features

- **⚡ Blazing Fast Streaming**: Server-Sent Events (SSE) stream tokens as they are generated by Groq.
- **🔐 Secure Key Storage**: Your Groq API key is stored locally in `.env` and never exposed to the client.
- **🎨 Modern Dark UI**: Sleek obsidian and glassmorphic aesthetic with ambient glow effects and micro-interactions.
- **🤖 Multi-Model Support**: Switch seamlessly between:
  - `llama-3.3-70b-versatile` (Flagship 128k context model)
  - `llama-3.1-8b-instant` (Ultra-fast lightweight model)
  - `mixtral-8x7b-32768` (Mixture of Experts)
  - `gemma2-9b-it` (Google's instruction tuned model)
- **💻 Syntax Highlighting**: Auto-detects programming languages with built-in copy buttons.
- **🎭 Customizable Personas**: Toggle system prompts between Senior Coder, Concise, Creative Writer, or custom prompts.
- **📤 Export Chats**: Download conversations as formatted Markdown files.

## 🚀 Quick Start Guide

### 1. Configure your Groq API Key

Open the `.env` file in this directory and add your Groq API key:

```env
GROQ_API_KEY=gsk_your_actual_groq_api_key_here
```

> **Need a free key?** Sign up and generate one in 30 seconds at [console.groq.com/keys](https://console.groq.com/keys).

*(You can also configure or verify your key directly inside the web interface)*.

### 2. Install Dependencies (if not already installed)

```bash
pip install -r requirements.txt
```

*(Flask, groq, and python-dotenv)*

### 3. Run the Flask Server

```bash
python app.py
```

### 4. Open in Browser

Visit **[http://127.0.0.1:5000](http://127.0.0.1:5000)** in your browser to start chatting!

## 🛠️ Configuration Options

You can customize default behavior in `.env`:

| Variable | Default | Description |
|---|---|---|
| `GROQ_API_KEY` | *(Required)* | Your Groq API key (`gsk_...`) |
| `DEFAULT_MODEL` | `llama-3.3-70b-versatile` | Default model when opening the app |
| `PORT` | `5000` | Local server port |
| `FLASK_ENV` | `development` | Flask runtime mode |
